# Idriç rising-sea foundations

This is a language-design target, not a claim about syntax already accepted by
the current compiler.

The design goal is a small local-to-global calculus that can serve geometry,
sensor regions, meshes, charts, local coordinate systems, configuration
overlays, and algebraic geometry without making any one of those domains the
primitive.

## 1. Shape and patch

A `Shape` is something that admits meaningful local pieces.

For a shape `X`, `Patch X` is the type of admissible patches of `X`.

A patch relation carries evidence, not a Boolean:

```idric
V ⊆ U
```

should be a type whose values witness that patch `V` lies inside patch `U`.

The minimal patch structure needs:

```text
whole patch
intersection / overlap
inclusion evidence
identity inclusion
composition of inclusions
```

Do **not** initially require every shape to have complements, unions of all
families, points, coordinates, a metric, or a topology represented as a set of
sets. Those can be additional structures.

## 2. Sections are indexed by patch

For local data `F` over `X`:

```idric
Section F U
```

means a section of `F` over exactly the patch `U`.

That patch index is the first important compiler guarantee. A value over one
patch cannot silently be used as though it lived over another.

## 3. Restriction

Restriction consumes evidence of inclusion:

```idric
restrict : V ⊆ U → Section F U → Section F V
```

The laws are part of the structure:

```text
restrict identity s = s

restrict (V⊆U composed with W⊆V) s
=
restrict W⊆V (restrict V⊆U s)
```

The compiler should be able to normalize or prove these laws for a lawful local
family. They should not survive forever as comments.

This is the contravariant heart of the construction: patches get smaller while
sections map in the opposite direction.

## 4. Overlap and compatibility

For patches `U` and `V`, let their overlap be `U ∩ V`.

Sections

```text
s : Section F U
t : Section F V
```

are compatible when their restrictions to the overlap are equal.

The equality should mention the canonical inclusion witnesses generated by the
patch system. This is where typed patches begin paying for themselves: comparing
sections over unrelated regions is rejected until both have been transported to
a common patch.

## 5. Gluing

A cover of `U` should be typed as a cover *of that U*. A compatible family of
sections over its members may then glue to a section over `U`.

Two logically separate properties matter:

- **local identity**: sections equal on a cover are equal;
- **gluing existence**: a compatible family has a glued section.

Together they give the sheaf condition.

Do not put covers into the base `Shape` interface unless needed. A useful
hierarchy is:

```text
Shape
  + PatchSystem
    + LocalFamily
      + SeparatedLocalFamily
        + Sheaf
```

The names are provisional; the separation of laws is not.

## 6. Ringed shapes and module-valued sections

Only after the sheaf core works should local scalars enter.

A ringed shape has a scalar sheaf `O`.

An `O`-module sheaf `F` then has, for each patch `U`,

```text
Section F U
```

as a module over

```text
Section O U.
```

Restriction must transport both scalars and module elements coherently.

This avoids the common type error of tensoring values that live over different
patches or over different local scalar rings.

## 7. Tensor belongs at the object level first

The generic operation is

```idric
F ⊗[O] G
```

for compatible `O`-module sheaves on the same ringed shape.

Restriction should commute with tensor up to the appropriate canonical
identification:

```text
(F ⊗ G)|V  ≅  (F|V) ⊗ (G|V).
```

Do **not** define the generic sheaf tensor merely by asserting

```text
Section (F ⊗ G) U = Section F U ⊗ Section G U
```

for every patch and every sheaf. That equality is too strong in general.

## 8. Quasicoherent / affine strengthening

There should be a stronger interface for the situation Vakil emphasizes.

For an affine patch

```text
U = Spec A
```

with a distinguished smaller patch

```text
V = D(f) = Spec A_f,
```

a quasicoherent module represented by `M` satisfies

```text
Section F U ≅ M
Section F V ≅ M_f.
```

Restriction is localization.

For two such modules:

```text
(M ⊗_A N)_f ≅ M_f ⊗_(A_f) N_f.
```

This is an excellent candidate for a first executable law because it ties all
four desired notions together:

```text
shape
patch
restriction
tensor
```

without requiring cohomology or derived categories.

## 9. Compiler-facing sketch

Provisional intent, deliberately not frozen grammar:

```idric
shape X

patch U on X
patch V on X

inside : V ⊆ U

family F on X

s : Section F U
s_on_V ≝ restrict s to V using inside
```

For module-valued local data:

```idric
ringed X with O

module_sheaf F over O
module_sheaf G over O

FG ≝ F ⊗[O] G
```

The surface form should read this way even if the bootstrap implementation
lowers it to ordinary dependent records.

## 10. First acceptance targets

A first Idriç implementation should prove only a small set of things:

1. a section cannot be passed where the patch index is wrong;
2. restriction along identity is definitionally equal or mechanically proved
   equal to the original section;
3. two consecutive restrictions equal restriction along composed inclusion;
4. compatibility on an overlap is well-typed;
5. an affine/quasicoherent fixture verifies that localization commutes with
   tensor.

No cohomology, schemes as a global language primitive, derived categories,
stacks, or spectral sequences are required for this slice.

That is enough to make "rising sea" structure real rather than decorative.
