# books

These are reading notes, not substitute editions of the sources.

The point of this directory is to extract the small amount of sheaf language
that should become reusable mathematical structure in Idriç:

- a shape has admissible patches;
- patches can sit inside other patches;
- data lives over a patch;
- data restricts along inclusion;
- compatible local data glues;
- local algebra can be transported and tensored coherently.

Where a source is freely readable, this repository links to the canonical or
best public copy. A file is mirrored here only when redistribution rights are
clear; "free to read" is not treated as "free to republish".

## First reading spine

1. [Vakil, *The Rising Sea*](vakil-rising-sea.md) — the working language.
2. [Serre, FAC](serre-fac.md) — coherent algebraic sheaves before schemes.
3. [Grothendieck, Tôhoku](grothendieck-tohoku.md) — the categorical/homological
   abstraction that makes sheaf cohomology ordinary derived-functor machinery.
4. [Stacks Project, Sheaves of Modules](stacks-sheaves-of-modules.md) — modern
   definition and lemma checker.

The implementation target is described in
[../idric/rising-sea-foundations.md](../idric/rising-sea-foundations.md).
